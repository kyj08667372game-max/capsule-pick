# 오늘의 운명, 피할 수 없습니다. (CAPSULE PICK)

> **공정하고 세련된 미래 과학 연구소의 양자 캡슐 추첨 시스템**  
> 식사비, 설거지, 청소 당번, 발표자 등 오늘의 주인공을 단 한 번의 공정한 캡슐 추첨으로 결정합니다.

---

## 🔬 프로젝트 소개

현실적인 미래 첨단 과학 연구실에 설치된 정밀 캡슐 추첨 기계를 웹 브라우저 상에 구현한 프로젝트입니다.  
과장된 게임 UI나 만화적 요소를 배제하고, 짙은 네이비/블랙 배경과 시안 블루, 네온 퍼플, 은은한 핑크 조명이 어우러진 사실적인 사이언스 랩 무드를 전달합니다.

---

## ✨ 핵심 기능

1. **공정한 암호학적 무작위 추첨 (CSP-RNG)**
   - `window.crypto.getRandomValues()`를 적용하여 모든 참가자가 동등한 당첨 확률을 가집니다.
   - 모듈로 편향(Modulo Bias)을 방지하는 정수 추출 알고리즘(Rejection Sampling)을 구현했습니다.
   - 추첨 시작 시 실제 당첨자를 확정하고, 애니메이션 타임라인과 100% 일치시켜 공정성을 보장합니다.

2. **긴장감 넘치는 4.5초 정밀 7단계 추첨 연출**
   - **1단계 (양자 코어 가속)**: 양자 코어 회전 가속 및 캡슐 와류(Vortex) 혼합, 기계 고주파 미세 진동(`is-rumbling`)
   - **2단계 (레이저 스캔)**: 시안 블루 레이저 빔이 하강하며 캡슐 반사광 표출 및 감속
   - **3단계 (타겟 록온)**: 당첨 캡슐에 네온 글로우 록온 링 표출, 타 캡슐 감광, 진동이 순간 멈추며 0.6초간의 숨막히는 정적
   - **4단계 (캡슐 추출 & 메카닉 흔들림)**: 캡슐을 파이프라인에서 뽑아올리며 기계 전체가 **덜컹! 덜덜덜!** 하고 요동치는 강력한 서스펜스 셰이크(`is-heavy-shake`) & 압력 게이지 급상승
   - **5단계 (결과 공개)**: **「운명 추출 완료!」** 문구와 함께 당첨자 이름이 선명한 네온 타이포그래피로 등장
   - **6단계 (결과 효과)**: 시안/퍼플/핑크 스파크 빛 입자가 방사된 후 리소스 자동 정리
   - **7단계 (재추첨)**: `다시 추첨하기` 버튼 활성화, 이전 당첨자도 공정하게 다시 추첨 대상에 포함

3. **1:1 실시간 캡슐 동기화 참가자 관리**
   - 이름 입력(Enter 지원), 참가자 추가/삭제 기능
   - 참가자 변경 시 챔버 내부의 캡슐 수와 이름 라벨이 1:1로 즉각 동기화
   - 공백 입력 방지, 중복 이름 등록 차단, 최대 12명 제한
   - 최소 2명 이상 등록 시에만 추첨 버튼 활성화 및 안내 메시지 제공
   - 점심 내기(4인), 청소 당번(6인) 빠른 테스트 프리셋 바 제공

4. **Web Audio API 내장 사운드 신시사이저 (SFX)**
   - 외부 음원 파일 다운로드 의존 없이 브라우저 내장 오디오 오실레이터로 연구실 앰비언트 험, 레이저 스위프, 록온 톤, 메카닉 충격음, 승리 챠임을 실시간 합성
   - 사운드 토글(AUDIO: ON/OFF) 버튼 지원

5. **반응형 디자인 및 웹 접근성**
   - 데스크톱: 연구원 관찰 패널(Dr. A. Thorne)과 대형 캡슐 기계 분할 뷰
   - 모바일: 주요 조작 및 캡슐 뷰 최적화
   - `prefers-reduced-motion` 미디어 쿼리 완벽 지원

- **Audio**: Web Audio API (Synthesizer)
